# Tuanbot 2026.5.6 更新说明 / Release Notes

## 中文

### 范围

- 上一个公开版本：`2026.5.5`
- 当前版本：`2026.5.6`
- 平台：Windows x64、macOS x64/arm64
- 构建日期：`2026-05-06`

### 亮点

#### 1. 更像桌宠，也更像 Agent

- Tuanbot 继续强化“桌宠 + Agent”的使用感
- 打开后就能聊天、执行任务、调用技能和 MCP 工具
- 适合日常玩耍，也适合轻量协作

#### 2. 一键安装更清晰

- Windows 和 macOS 安装包继续保持同一版本号
- 安装包命名、更新元数据和 README 说明已经同步
- 下载后即可安装，不需要额外配置复杂流程

#### 3. 内置 Skills 开箱即用

- Skills 不需要用户单独安装
- 打开应用就能直接使用
- 列表中会明确标注内置和只读状态

#### 4. 原生 IM 工具仍可使用

- 登录后仍然可以接入原生 IM 工具
- 日常消息沟通和 Agent 工作流可以放在同一个桌面入口里

#### 5. 多语言体验继续推进

- 聊天窗口、设置页、背包页等核心界面继续使用统一多语言层
- 默认语言会跟随系统语言自动选择
- 用户仍然可以手动切换语言并保留自己的偏好

#### 6. 安装包已经按新版本重新发布

- 本次发布使用 `2026.5.6`
- Windows 与 macOS 安装包、blockmap、更新清单已经统一到新版本号

### 下载

- Windows x64：`tuanbot_win_2026.5.6.exe`
- Windows 稳定直链：`tuanbot_win_latest.exe`
- macOS Apple Silicon：`Tuanbot-2026.5.6-mac-arm64.dmg`
- macOS Intel：`Tuanbot-2026.5.6-mac-x64.dmg`

## English

### Scope

- Previous public release: `2026.5.5`
- Current version: `2026.5.6`
- Platforms: Windows x64, macOS x64/arm64
- Build date: `2026-05-06`

### Highlights

#### 1. More like a desktop pet, more like an agent

- Tuanbot keeps leaning into the “desktop pet + agent” experience
- It can chat, execute workflows, and call Skills and MCP tools right away
- It is meant to be playful and practical at the same time

#### 2. One-click installation is clearer

- Windows and macOS installers continue to share the same version line
- Installer names, update metadata, and README copy are aligned
- No extra setup is required before using the app

#### 3. Built-in Skills work out of the box

- Skills do not need to be installed separately by users
- They are available immediately after opening the app
- The Skills list clearly marks built-in and read-only entries

#### 4. Native IM tools still work

- After login, native IM tools remain available
- Everyday messaging and agent workflows can stay in one desktop surface

#### 5. Localization keeps moving forward

- Chat, settings, inventory, and other core surfaces continue to use one localization layer
- The default language follows the user's system locale
- Manual language switching remains available

#### 6. The release assets were refreshed

- This release uses version `2026.5.6`
- Windows/macOS installers, blockmaps, and update manifests are aligned to this version line
