# Tuanbot 2026.5.5 更新说明 / Release Notes

## 中文

### 范围

- 上一个公开版本：`2026.5.2`
- 当前版本：`2026.5.5`
- 平台：Windows x64、macOS x64/arm64
- 构建日期：`2026-05-05`

### 亮点

#### 1. 内置 Skills 开箱即用

- Anthropic skills 已作为内置能力打包进 Tuanbot
- 用户打开应用后就可以直接使用，不需要再单独安装
- Skills 列表里会清晰显示内置来源和只读状态

#### 2. 多语言体验开始统一

- 聊天窗口、设置页、背包页等核心界面已接入统一多语言层
- 默认语言会跟随系统语言自动选择
- 用户仍然可以手动切换语言，并保留自己的设置

#### 3. 发行版信息统一到同一版本号

- Windows、macOS 包现在共用同一个版本号：`2026.5.5`
- 平台差异保留在文件名中，不再体现在版本号里
- release 仓 README、release notes 和下载链接已经同步更新

#### 4. 下载体验更清晰

- Windows 版本化安装包与稳定直链并存
- macOS Apple Silicon / Intel 分开提供，方便对应芯片下载
- 自动更新元数据继续保持完整，方便应用内升级

### 下载

- Windows x64：`tuanbot_win_2026.5.5.exe`
- Windows 稳定直链：`tuanbot_win_latest.exe`
- macOS Apple Silicon：`Tuanbot-2026.5.5-mac-arm64.dmg`
- macOS Intel：`Tuanbot-2026.5.5-mac-x64.dmg`

## English

### Scope

- Previous public release: `2026.5.2`
- Current version: `2026.5.5`
- Platforms: Windows x64, macOS x64/arm64
- Build date: `2026-05-05`

### Highlights

#### 1. Built-in Skills work out of the box

- Anthropic skills are bundled directly into Tuanbot
- Users can start using them immediately after opening the app
- The Skills list now shows built-in sources and read-only status clearly

#### 2. A more unified localization experience

- Chat, settings, inventory, and other core surfaces now use one localization layer
- The default language follows the user's system locale
- Users can still switch languages manually and keep their preference

#### 3. Release assets now share one version line

- Windows and macOS packages now share the same version number: `2026.5.5`
- Platform differences remain in the file names rather than the version string
- README, release notes, and download links in the release repo are all aligned

#### 4. Downloading is clearer

- Versioned Windows installers and a stable Windows direct link are both available
- macOS Apple Silicon and Intel installers are published separately for convenience
- Auto-update metadata remains complete for in-app upgrade flows
